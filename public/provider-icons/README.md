# Provider brand icons

These SVGs are unmodified brand marks from [LobeHub Icons](https://github.com/lobehub/lobe-icons), pinned to commit `329f378cbd1a88f45b60cd096b9111ce16f3ea39`, except for the Xiaomi mark from [Simple Icons](https://github.com/simple-icons/simple-icons).

`sources.json` records the original URLs, commits and SHA-256 checksums. `LICENSE` contains the LobeHub MIT license and `LICENSE.simple-icons` contains the Simple Icons CC0 license. All icons are bundled locally; displaying them makes no network requests.

The `glm` asset is the Zhipu brand mark. The `mimo` asset is the Xiaomi brand mark, displayed in Xiaomi orange with a CSS mask.
