# UI icons

`lucide.ts` contains SVG nodes generated from the [official Lucide SVGs](https://github.com/lucide-icons/lucide), pinned to commit `5a92b9ba262de5bf10e864219883267672c05db8`.

`sources.json` records the exact source for each icon. These paths are shared by React controls and the selection translation panel in Shadow DOM. `LICENSE` contains the upstream ISC / Feather MIT notices; a copy ships with the extension in `licenses/lucide.txt`.
